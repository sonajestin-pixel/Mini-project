# Sales Analytics Project (Excel + Power BI)

This project is a complete **Sales Analytics Dashboard** built using **Excel** for data cleaning and **Power BI** for modeling, visualizations, and insights.  
The objective is to understand sales performance, analyze product trends, evaluate regional contributions, and identify revenue growth patterns.

---

# 1. Excel Data Cleaning & Preparation

### Steps Performed
- Removed duplicate records from the dataset  
- Standardized text fields  
- Cleaned date column and ensured a consistent date format  
- Removed null or missing values  
- Fixed incorrect number formats  
- Trimmed extra spaces and corrected case formatting  
- Verified product, quantity, and price fields  
- Added month and year helper columns for analysis  
- Finalized a clean base dataset for Power BI  

---

# 2. Power BI Data Modeling & Transformations

### Power Query Steps (Data Preparation)
- Corrected data types   
- Removed unnecessary columns  
- Replaced nulls with appropriate values  
- Extracted Year, Month, and Month Name from the Date column  
- Renamed columns for consistency and clarity  
- Ensured a clean, optimized dataset ready for reporting  

### Power BI Setup
- Loaded the cleaned Sales table  
- Created a simple Date table for visuals requiring a proper date hierarchy  
- Built relationships automatically handled by Power BI (if applicable)  
- Designed dashboards using clean, modern visualization standards
